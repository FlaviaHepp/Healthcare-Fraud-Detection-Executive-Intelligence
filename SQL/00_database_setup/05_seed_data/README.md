# Seed Data

This folder is reserved for optional, non-sensitive sample data used to validate the database setup.

No fabricated production-like records are included here.

When sample seed scripts are added, they should:

1. Contain only synthetic or redistribution-approved data.
2. Be small enough to run quickly.
3. Load dimensions before the fact/claims table.
4. Preserve the primary-key and foreign-key relationships.

The main project dataset should remain documented separately under:

```text
data/raw/
```
