# Models

This folder contains machine learning artifacts generated by the healthcare fraud detection workflow.

## Objective

Identify potentially fraudulent healthcare claims while supporting model comparison, optimization, evaluation, and explainability.

## Modeling Workflow

```text
Data Preparation
      ↓
Feature Engineering
      ↓
Train / Test Split
      ↓
Model Benchmarking
      ↓
Hyperparameter Optimization
      ↓
Model Evaluation
      ↓
Explainability
      ↓
Prediction Export
```

## Models Evaluated

- Logistic Regression
- Random Forest
- XGBoost
- LightGBM
- CatBoost

## Evaluation

The project evaluates models using Accuracy, Precision, Recall, F1 Score, ROC-AUC, and Confusion Matrix.

Precision and Recall are especially relevant in fraud detection because false positives increase investigation costs while false negatives may leave suspicious claims undetected.

## Explainability

Explainability is used to understand which features contribute to model predictions. The project incorporates **SHAP** and, where applicable, **LIME**.

## Model Artifacts

Depending on the execution environment, this folder may contain trained model files, model-comparison outputs, and model metadata.

Large binary artifacts should only be committed when they are required for reproducibility and are appropriate for repository storage.

## Reproducibility

Model artifacts should be generated from the scripts in the `python/` directory using the documented preprocessing and training workflow.
