# 📌 Screenshot Guidelines

To keep the repository professional:

* Use high-resolution screenshots.
* Avoid screenshots containing unnecessary desktop elements.
* Keep dashboard filters visible when they help explain the analysis.
* Use consistent naming conventions.
* Avoid uploading multiple versions of the same dashboard.
* Prioritize the most relevant analytical views.
* Keep the number of screenshots limited.

### Recommended maximum

**4–6 screenshots** for the final repository.

The objective is quality over quantity.
